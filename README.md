# Teamable_App
Teamable Application
Overview:

Teamable is a full-stack web application developed as part of an IT Fundamentals and Software Development training program.
The project was designed to simulate a real-world software development workflow, taking the application through the complete Software Development Life Cycle (SDLC), from planning and development to testing, deployment, and version control.

This is application for managing employees profile. 
It demonstrates how modern web applications are built using a frontend, backend, database, testing framework, and cloud-based deployment environment.

Features:
Responsive user interface built with Vue.js
Dynamic frontend functionality using JavaScript
Backend API developed with Node.js
Data storage and retrieval using MongoDB
Frontend-to-backend communication through HTTP requests
Automated unit and integration testing with Jest
Application packaging and deployment workflow
Environment-based configuration management
Version control using Git
